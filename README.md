
## Getting Started

Follow the steps below to set up the environment and run the experiments.

### 1. Create Environment
We provide a Conda environment file `env_conch.yml` to ensure all dependencies are installed correctly. 

Run the following command to create the environment:
```bash
conda env create -f env_conch.yml
```

### 2. Run Experiments
After activating the environment, you can directly run the Jupyter Notebook to reproduce the experiments and generate the figures.
```bash
jupyter notebook experiments.ipynb
```
